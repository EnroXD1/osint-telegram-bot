# Проверка версии от 04.10.2026

Проверено на Windows, Python 3.12.14. Установленные версии основных зависимостей: aiogram 3.31.0, httpx 0.28.1, phonenumbers 9.0.40.

## Автоматические проверки

`python -m unittest discover -s tests -v`: **37 тестов прошли**.

Проверки охватывают распознавание приведённых примеров, отклонение локальных адресов и некорректных ссылок, контрольные цифры реквизитов, локальную проверку телефона, передачу только домена email, выбор RDAP-сервера по реестру IANA, запрет перенаправления на localhost, обработку ошибок и частичных ответов API, экранирование HTML, ограничение размера сообщений, частоты запросов и памяти счётчиков. Обработчики Telegram проверены на подставных событиях: меню, текстовый поиск, список разрешённых пользователей, игнорирование групп и отсутствие скачивания фото.

Карточка Telegram дополнительно проверена на подставных ответах `ChatFullInfo`: публичный канал и группа, ID и источник, экранирование названия/описания, отсутствие необязательного описания, исключение личных чатов и чатов личных сообщений канала, недоступный аккаунт, ошибка сети и маршрут запроса `@логин`. Настоящий запрос к Telegram API после обновления не выполнялся.

Brave проверен с `httpx.MockTransport`: загрузка ключа из окружения без вывода в `repr`, команда `/search` и кнопка меню, принятие имени/ника и отклонение телефона/email/даты рождения, фиксированный HTTPS-адрес API, ключ только в заголовке, один запрос без повторов и без посещения найденных страниц. Проверены максимум пять ссылок, удаление дублей, фильтрация небезопасных URL, экранирование заголовков, отсутствие фрагментов текста и дополнительных полей в ответе. Проверены отсутствие ключа, пустая выдача, неверная структура/JSON, ответы 401/403/429/503, перенаправление и ошибка соединения без раскрытия ключа. Остальные команды не вызывают Brave даже при наличии ключа.

`python -m pip check`: конфликтов зависимостей не найдено.

CLI-проверка телефона без Telegram работает. Запуск без BOT_TOKEN выводит инструкцию и завершается, не открывая polling.

## Настоящие сетевые запросы

| Пример | Наблюдение |
|---|---|
| `example.com` | Получены A, AAAA, MX, NS и регистрационные сведения из RDAP Verisign |
| `1.1.1.1` | Получены диапазон и название сети из APNIC RDAP; PTR `one.one.one.one.` |
| `/vin 1HGCM82633A004352` | NHTSA вернул HONDA Accord, модельный год 2003 и код результата 0 |
| `test@example.com` | DNS вернул Null MX `0 .`; полный email не отправлялся в API |
| `github.com/octocat` | GitHub API ограничил доступ в текущей среде. Успешный ответ профиля и обработка отказа проверены с подставными ответами; доступ к настоящему профилю не подтверждён |

Сетевые ответы могут изменяться. Проверки выполнялись только на указанных публичных примерах.

## Что ещё не проверено

- Настоящий обмен сообщениями с Telegram: токен собственного бота не предоставлен. Подставные события не заменяют проверку `/start` после запуска.
- DaData: API-ключ не предоставлен. Формат запроса и фильтрация результатов юридических лиц проверены с подставными ответами.
- Brave Search: API-ключ не предоставлен. Настоящий платный запрос и расход квоты не выполнялись; интеграция проверена на подставных ответах.
- Docker-сборка и работа на сервере.
- Содержание профилей VK, TikTok, Instagram и OK: API не подключены, реализованы только ссылки.
